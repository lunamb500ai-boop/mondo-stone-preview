# Image credits and edits

All photographs are Mondo Stone's own job photos (source folder `_src-photos/iCloud Photos from DAVID MAZZEO/`, not published).

Every output had the same pipeline applied, in this order: EXIF orientation applied; crop to the box and aspect below (to remove site clutter); white balance from the brightest unclipped pixels at 60% strength, gain capped at ±10% per channel; levels set on luminance with 0.4% clipped at each end (same stretch on all channels, so stone colour is not shifted); gentle mid-tone gamma; very slight S-curve contrast; resize (Lanczos) to max 1600 px long edge — never upscaled, so some are smaller; mild unsharp mask; saved as progressive JPEG q82 and WebP q80 with all EXIF/GPS metadata stripped. An `-800` version of each is exported for `srcset`. No generative or AI fill, no retouching/cloning, no noise reduction was needed.
